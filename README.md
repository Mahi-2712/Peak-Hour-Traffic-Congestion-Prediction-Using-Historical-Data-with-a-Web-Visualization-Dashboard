# Peak-Hour Traffic Congestion Prediction Using Historical Data with a Web Visualization Dashboard

This project predicts traffic congestion during peak hours using historical traffic data and machine learning techniques. The system analyzes factors such as traffic volume, time, day, and other relevant features to identify congestion patterns.

A web-based dashboard built using **Streamlit** provides an easy-to-use interface for viewing traffic data, predictions, and visualizations. The project helps users understand traffic patterns and supports better planning and decision-making.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Folium
* Geopy
* Matplotlib/visualization tools

## Main Features

* Historical traffic data analysis
* Peak-hour congestion prediction
* Data visualization
* Interactive web dashboard
* Easy-to-understand prediction results
* Location-based traffic visualization

## Objective

The main objective of this project is to use historical traffic data and machine learning to predict peak-hour traffic congestion and present the results through an interactive web dashboard.
